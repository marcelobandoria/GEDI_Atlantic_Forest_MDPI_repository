# GEDI Atlantic Forest Structural Metrics Repository

This repository contains the analytical data, spatial sampling files, R scripts, derived tables, figures, metadata, and documentation associated with the manuscript:

**Regional comparison of Atlantic Forest physiognomies using GEDI-derived structural metrics**

The repository is intended to support transparency, reproducibility, and long-term archiving of the data-dependent results reported in the manuscript and Supplementary Information.

## Study overview

The study compares GEDI-derived forest structural metrics among old-growth candidate forest polygons in four Brazilian Atlantic Forest physiognomies:

- Dense Ombrophilous Forest (DOF)
- Mixed Ombrophilous Forest (MOF)
- Seasonal Semideciduous Forest (SSdF)
- Seasonal Deciduous Forest (SDF)

The structural metrics analyzed are:

- Canopy height (H, m)
- Aboveground biomass density (AGBD, Mg ha^-1)
- Plant area index (PAI, m^2 m^-2)
- Canopy cover (COVER, %)
- Foliage height diversity (FHD)

The repository workflow reproduces the data-dependent tables and figures cited in the submitted manuscript and Supplementary Information.

## Required input files

Before running the workflow, the repository must contain:

```text
data/gedi_footprints_filtered.csv
spatial/old_growth_candidate_polygons.gpkg
```

The polygon GeoPackage must contain the layer:

```text
atual__samples
```

The expected polygon ID field is:

```text
id
```

## Quick test

Use this mode only to test whether the workflow runs without errors. It reduces bootstrap iterations and figure resolution.

```r
Sys.setenv(GEDI_FAST_TEST = "true")
source("scripts/00_run_repository_workflow.R")
```

## Final reproducibility run

Use this mode for the final repository release.

```r
Sys.unsetenv("GEDI_FAST_TEST")
source("scripts/00_run_repository_workflow.R")
```

```text

```

These files indicate whether each data-dependent table and figure cited in the manuscript and Supplementary Information is generated by scripts or is an external/static asset.

## Static manuscript figures

Figures 1–6 in the manuscript are cartographic, visual interpretation, or diagrammatic assets. They are not regenerated by the R statistical workflow. The final exported versions should be archived under:

```text
manuscript_assets/figures/
```

See `metadata/static_assets_manifest.csv` and `documentation/STATIC_ASSETS_GUIDE.md` for expected filenames and descriptions.
